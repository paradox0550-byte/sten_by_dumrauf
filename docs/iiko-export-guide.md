# Экспорт продаж из iikoOffice для STEN

## Рекомендуемый отчёт

Откройте «Отчёты → OLAP-отчёт по продажам». Для почасовой детализации используйте измерения:

- Учетный день;
- Час закрытия (или часовой интервал, если выгрузка подготовлена именно по часам);
- Блюдо;
- Категория номенклатуры / группа блюд.

В показателях добавьте количество блюд и сумму со скидкой. Себестоимость — необязательное поле для отдельной аналитики.

Экспортируйте XLSX с одной строкой заголовков в первой строке листа. Парсер распознаёт распространённые варианты русских заголовков, но не угадывает отсутствующие измерения.

## Важные условия

- Одна строка должна описывать дату, час, блюдо и категорию.
- Для расчёта ФОТ необходима детализация по часу. Дневные итоги нельзя интерпретировать как почасовые продажи.
- Если категория отсутствует, добавьте измерение «Категория номенклатуры» или группу блюд.
- Модификаторы не должны увеличивать количество произведённых блюд; строки с заполненными полями модификатора исключаются.
- Промежуточные итоги не являются строками продаж и пропускаются.

## Распределение по зонам

Начальный справочник категорий — только подсказка. Пользовательский маппинг имеет приоритет. Незнакомые категории помещаются в отдельный список нераспределённых продаж и не участвуют в расчёте труда.

## Контроль качества

После разбора проверьте число корректных, ошибочных, пропущенных и нераспределённых строк, а также суммы распределённой и нераспределённой выручки. Если есть ошибки или неизвестные категории, отчёт должен явно показывать неполноту данных.
