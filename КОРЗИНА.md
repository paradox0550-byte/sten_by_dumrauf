## 5. CSS audit / quarantine notes

- `src/styles/trash/README.md` удалён после переноса его правил сюда; в каталоге не было самих quarantine stylesheets.
- `src/app.css` — активный глобальный импорт с legacy/embedded blocks; не удалять целиком без полного import/reference map, анализа селекторов и browser comparison.
- По состоянию на `main` все глобальные CSS-слои ниже реально импортируются в `src/main.tsx`: `tokens.css`, `app.css`, `unified-interface.css`, `operations-calm.css`, `mobile-experience.css`, `sten-visual-system.css`, `visual-system/index.css`. Ни один из них нельзя объявить dead CSS по текущему import graph.
- `src/styles/tokens.css` — активный compatibility entrypoint; он импортирует канонические `visual-system/tokens.css`.
- `src/styles/visual-system/index.css` импортирует `tokens.css`, `shell.css`, `components.css`, `responsive.css`; это активный составной слой, не дубль.
- Страничные стили тоже используются: `src/styles/pnl.css` через `src/pages/PnL.css`, `src/styles/chat.css` через `src/pages/AI.tsx`, `src/styles/telegram-monitor.css` через `src/pages/TelegramMonitor.tsx`.
- `src/app.css` — 10 425 строк / около 297 KB, 156 `!important`, 138 media queries; активная legacy-основа. Не удалять и не переписывать wholesale.
- `unified-interface.css` содержит 123 `!important`; `sten-visual-system.css` — 69; `visual-system/shell.css` — 39; `components.css` — 27; `responsive.css` — 14. Порядок слоёв и cascade важны: простое перемещение в `@layer` может изменить приоритет.
- Пересечения селекторов — только кандидаты на анализ. Удалять можно лишь доказанные одинаковые declarations при сохранении media boundaries, specificity, cascade order и !important semantics; обязательны визуальные сравнения light/dark на mobile/tablet/desktop.
